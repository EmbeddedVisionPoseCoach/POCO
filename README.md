# 3. Key Features (주요 기능)
- **Mediapipe Holistic Fine Tuning**:
  - 미디어파이프 내부 모델을 파인튜닝 후 새로운 랜드마크 구성.

- **자세 분석 모델**:
  - 사용자 자세를 실시간 분석해서 자세 판단을 내려주는 모델 구현.

- **하드웨어 피드백**:
  - 알림
  - 방석 진동

- **자세 분석한 데이터를 활용한 UI제공 **:
  - 시간 단위 OR 하루 단위로 데이터 측정 후 휴식 가이드 및 피드백제공
